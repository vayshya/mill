= VCS Versioning

Mill derives version information from Git history through
`mill.util.VcsVersion`. The result is used by the build's `millVersion`
and `millLastTag` tasks.

This feature covers Git tag discovery, commit counting, revision formatting,
dirty-working-tree detection, and the build-level fallback when no tag is
available.

The current behavior and characterization scenarios are specified in
link:requirements.adoc[VCS Versioning Requirements].

The implementation is in `libs/util/src/mill/util/VcsVersion.scala`;
the existing formatting tests are in
`libs/util/test/src/mill/util/VcsVersionTests.scala`.
